GUI 앱 없이 터미널 한 줄로 재연결 — 키체인 비번 자동 입력, 문자 OTP, 유휴 끊김 방지(keepalive)까지.
macOS OpenVPN gov-ncloud Makefile Zero-config 재접속

🚀 빠른 시작

설치는 한 번, 이후엔 vpn 한 줄.

1 🔧

make setup

아이디·프로필 입력, VPN 비밀번호를 macOS 키체인에 저장.

2 📦

make install

클라이언트·root 래퍼·NOPASSWD 설치. 단축 명령(별칭) 선택.

3 📡

naver-vpn

문자 OTP만 입력하면 연결 + keepalive 자동 시작.

⚙️ 동작 방식

앱이 내부적으로 쓰는 2단계 인증(/api/v3 + OpenVPN)을 그대로 재현한다.

🔐

① 로그인 — authstate

키체인 비밀번호로 포털에 인증 요청. 서버가 비번을 검증한다.

POST /api/v3/authstate · Api-Version: 1
📱

② 문자 OTP 발송

인증 성공 시 서버가 등록된 휴대폰으로 OTP를 보내고, state 토큰과 .ovpn 프로필(base64)을 응답한다.

⌨️

③ OTP 입력

문자로 받은 OTP를 입력. 이 값이 곧 OpenVPN 인증의 비밀번호가 된다.

auth-file = 아이디 ⏎ OTP
🔌

④ OpenVPN 연결

root 래퍼가 받은 프로필로 openvpn을 실행. 게이트웨이가 OTP로 최종 인증한다.

sudo naver-vpn-up · openvpn --daemon
🟢

⑤ 연결 완료

utun 인터페이스에 10.0.0.x 가 할당되고 사내망에 접근 가능. keepalive가 자동으로 시작된다.

💡 핵심
/api/v2 는 서버에서 폐기되어 항상 실패한다. 실제 경로는 /api/v3 — mitmproxy로 앱 트래픽을 캡처해 확인했다.

🔑 헷갈리는 세 가지 비밀번호

각 단계가 요구하는 비밀번호가 다르다 — 한 장으로 정리.

🔑

VPN 비밀번호

make setup 때 1회.
키체인에 저장되어 이후 자동 입력.

🔐

맥 sudo 비밀번호

make install 때.
이 컴퓨터(macOS) 로그인 암호.

📱

문자 OTP

naver-vpn 실행마다.
SMS로 받는 일회용 — 자동화 불가.

🔁 유휴 끊김 방지 (keepalive)

서버는 실제 데이터 트래픽이 없으면 세션을 끊는다(INACTIVE_TIMEOUT).

🛰️

어떻게

연결 후 데몬이 주기마다 터널 너머 게이트웨이(10.0.0.1)로 핑을 보내 트래픽을 유지한다. openvpn이 죽거나 핑이 연속 실패하면 스스로 종료.

⚠️

주의

핑 대상은 터널 너머 IP여야 한다. 로컬 터널 IP(10.0.0.4)로 핑하면 터널을 타지 않아 효과가 없다.

설정기본설명
KEEPALIVE1연결 후 자동 시작 (0=끔)
KEEPALIVE_INTERVAL60핑 주기(초)
KEEPALIVE_HOST10.0.0.1핑 대상(게이트웨이)
KEEPALIVE_FAILS3연속 실패 N회면 종료

🛡️ 보안

🔑

비밀번호는 키체인에만

설정 파일·스크립트에 평문으로 남지 않는다. 전송은 앱과 동일하게 HTTPS.

🧴

OTP는 일회용·자동삭제

인증파일은 /tmp(권한 600)에 만들고 종료 시 삭제. openvpn은 --auth-nocache.

🔒

최소 권한 NOPASSWD

openvpn에 직접 NOPASSWD를 주면 사실상 전체 root. 대신 동작이 고정된 root 래퍼에만 허용.

🧱

래퍼 입력 검증

설정 디렉토리를 코드에 고정하고, 프로필명(*.ovpn)·인증파일 경로를 검증한다.
